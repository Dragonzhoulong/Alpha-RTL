You are an expert digital circuit designer specializing in high-performance arithmetic units.

## Task

Implement a Verilog module `ct_vfmau_lza_simd_half` — a 24-bit Leading Zero Anticipator (LZA) for the SIMD half-precision datapath of the floating-point multiply-accumulate unit (VFMAU) in an out-of-order RISC-V CPU. The module has two stages: (1) pre-encoding and (2) priority encoding.

## Stage 1: Pre-encoding (MUST be implemented exactly as specified)

Compute carry signals and derive `lza_precod[23:0]`. These formulas are the LZA algorithm and MUST be implemented exactly — do NOT modify them.

```verilog
// Carry signals
assign carry_p[23:0] = summand[23:0] ^ addend[23:0];   // propagate
assign carry_g[23:0] = summand[23:0] & addend[23:0];   // generate
assign carry_d[23:0] = ~(summand[23:0] | addend[23:0]); // delete

// Pre-code bit 0 (special case — uses carry_p[1])
assign lza_precod[0] =
     carry_p[1] && (carry_g[0] && sub_vld || carry_d[0])
 || !carry_p[1] && (carry_d[0] && sub_vld || carry_g[0]);

// Pre-code bit 23 (special case — MSB boundary)
assign lza_precod[23] =
     sub_vld && (carry_g[23] && !carry_d[22] || carry_d[23] && !carry_g[22])
 || !sub_vld && (carry_d[23] && !carry_d[22] || !carry_d[23]);

// Pre-code bits [22:1] (general case — uses carry_p[i+1], carry_g/d[i], carry_g/d[i-1])
assign lza_precod[22:1] =
    carry_p[23:2] & (carry_g[22:1] & ~carry_d[21:0] | carry_d[22:1] & ~carry_g[21:0])
 | ~carry_p[23:2] & (carry_g[22:1] & ~carry_g[21:0] | carry_d[22:1] & ~carry_d[21:0]);
```

## Stage 2: Priority Encoding (this is where you optimize)

Find the position of the most-significant '1' in `lza_precod[23:0]` and encode it as a 5-bit count **from the MSB**. This is where you have freedom to choose your implementation strategy.

**CRITICAL — encoding direction is MSB-first (position counts DOWN from bit 23):**

| lza_precod pattern | lza_result | Meaning |
|-|-|-|
| `24'b1xxxxxxxxxxxxxxxxxxxxxxx` (bit 23 set) | `5'd0` | Leading one at MSB, 0 leading zeros |
| `24'b01xxxxxxxxxxxxxxxxxxxxxx` (bit 22 is first '1') | `5'd1` | 1 leading zero |
| `24'b001xxxxxxxxxxxxxxxxxxxxx` (bit 21 is first '1') | `5'd2` | 2 leading zeros |
| ... | ... | ... |
| `24'b00000000000000000000001x` (bit 1 is first '1') | `5'd22` | 22 leading zeros |
| `24'b000000000000000000000001` (bit 0 is first '1') | `5'd23` | 23 leading zeros |
| `24'b000000000000000000000000` (all zeros) | `5'd24` | No leading one |

The formula is: **`lza_result = 23 - (position of highest set bit)`**. So bit 23 → result 0, bit 0 → result 23, no bits set → result 24.

`lza_result_zero = 1` when `lza_precod` is all zeros (i.e., `~|lza_precod[23:0]`).
