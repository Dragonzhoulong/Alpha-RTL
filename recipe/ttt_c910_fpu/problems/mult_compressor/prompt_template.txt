## Task

Implement a Verilog module `ct_vfmau_mult_compressor` — a Booth radix-4 multiplier compressor tree for the floating-point multiply-accumulate unit (VFMAU) of an out-of-order RISC-V CPU.

## Module Interface (MUST match exactly)

```verilog
module ct_vfmau_mult_compressor(
  carry,                            // output [105:0]
  cp0_vfpu_icg_en,                  // input
  cp0_yy_clk_en,                    // input
  dp_xx_ex1_double,                 // input — double precision mode
  dp_xx_ex1_half,                   // input — half precision mode
  dp_xx_ex1_single,                 // input — single precision mode
  forever_cpuclk,                   // input — clock
  mult1_ex1_op0_half0_hidden_bit,   // input — op0 half hidden bit
  mult1_ex1_op0_hidden_bit,         // input — op0 hidden bit (1=normal, 0=denormal)
  mult1_ex1_op1_half0_hidden_bit,   // input — op1 half hidden bit
  mult1_ex1_op1_hidden_bit,         // input — op1 hidden bit
  op0_frac,                         // input  [51:0] — operand 0 fraction
  op1_frac,                         // input  [51:0] — operand 1 fraction
  pad_yy_icg_scan_en,               // input
  pipe_down,                        // input — pipeline enable
  simd_half0_product,               // output [21:0] — SIMD half result
  sum                               // output [105:0]

```

## Functional Specification

1. **Operand preparation**: Form 54-bit multiplicand/multiplier as {2'b0, op0_frac[51:0]} and {2'b0, op1_frac[51:0]}.

2. **Booth radix-4 encoding**: Generate 27 partial products from the multiplier using Booth radix-4 encoding. Each 3-bit slice of the multiplier selects one of: 0, +A, +2A, -2A, -A (where A = multiplicand[52:0]).

3. **Multi-precision support**:
   - **Double** (dp_xx_ex1_double=1): Full 54×54 multiplication, all 52 mantissa bits active
   - **Single** (dp_xx_ex1_single=1): Lower 23 bits of fraction active
   - **Half** (dp_xx_ex1_half=1): Lower 10 bits of fraction active
   Only one mode is active at a time. Partial products are masked/gated per mode.

4. **Denormal handling**: When hidden bit = 0, the corresponding partial product is zeroed out. `oper_norm = op0_hidden & op1_hidden`.

5. **Compressor tree reduction**: Reduce 27 partial products + sign correction bits to carry-save form (sum + carry) using 4:2 and 3:2 compressor cells.

6. **Pipeline register**: There MUST be a pipeline register (EX1→EX2 boundary) that latches intermediate results on `posedge forever_cpuclk` when `pipe_down=1`. The gated clock cell uses `cp0_vfpu_icg_en`, `cp0_yy_clk_en`, `pad_yy_icg_scan_en` for clock gating.

7. **SIMD half product**: `simd_half0_product[21:0]` is computed from the half-precision partial products (combinational, no pipeline delay).

8. **Output**: `sum[105:0]` and `carry[105:0]` are the final carry-save redundant form of the multiplication result (computed in EX2, combinational from pipeline registers).
