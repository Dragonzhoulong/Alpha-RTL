You are an expert digital circuit designer specializing in high-performance arithmetic units.

## Task

Implement a Verilog module `ct_vfmau_lza` — a 108-bit Leading Zero Anticipator (LZA) for the floating-point multiply-accumulate unit (VFMAU) of an out-of-order RISC-V CPU.

## Module Interface (MUST match exactly)

```verilog
module ct_vfmau_lza(
  addend,                           // input  [107:0]
  lza_result,                       // output [6:0]
  sub_vld,                          // input
  summand                           // input  [107:0]
);
```

## Functional Specification

The LZA predicts the number of leading zeros in the result of `summand + addend` (or `summand - addend` when `sub_vld=1`) **before** the actual addition. This enables overlapping normalization shift with the adder, saving a full cycle in the FP pipeline.

### Step 1: Pre-encoding

Compute bit-wise carry signals from summand and addend:
- `carry_p[107:0] = summand ^ addend` (propagate)
- `carry_g[107:0] = summand & addend` (generate)
- `carry_d[107:0] = ~(summand | addend)` (delete/kill)

Derive the LZA pre-code `lza_precod[107:0]`:
- Bit 0: `carry_p[1] & (carry_g[0] & sub_vld | carry_d[0]) | ~carry_p[1] & (carry_d[0] & sub_vld | carry_g[0])`
- Bit 107: `sub_vld & (carry_g[107] & ~carry_d[106] | carry_d[107] & ~carry_g[106]) | ~sub_vld & (carry_d[107] & ~carry_d[106] | ~carry_d[107])`
- Bits [106:1]: `carry_p[i+1] & (carry_g[i] & ~carry_d[i-1] | carry_d[i] & ~carry_g[i-1]) | ~carry_p[i+1] & (carry_g[i] & ~carry_g[i-1] | carry_d[i] & ~carry_d[i-1])`

Each bit of `lza_precod` is '1' at positions where the leading one of the add/subtract result might be located.

### Step 2: Priority Encoding

Find the position of the most significant '1' in `lza_precod[107:0]` using a hierarchical encoder. The result is a 7-bit value:
- `lza_result = 0` means the leading one is at bit 107 (MSB)
- `lza_result = 107` means the leading one is at bit 0 (LSB)
- `lza_result = 108` means no leading one found (all zeros)

### Output

`lza_result[6:0]` — the predicted leading zero count (7 bits, range 0..108).
